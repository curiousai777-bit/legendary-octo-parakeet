# PortfolioAI

PortfolioAI is a niche-aware career portfolio platform for students.

## MVP

PortfolioAI helps a student:

1. Choose how they want to complete onboarding.
2. Discover or confirm their career niche.
3. Answer niche-specific questions.
4. Assess what evidence and experience they already have.
5. Identify portfolio gaps.
6. Get project ideas tailored to their niche and skill level.
7. Turn an idea into a step-by-step project brief.
8. Generate project and portfolio content with AI assistance.
9. Edit the generated portfolio.
10. Publish a shareable portfolio.

The architecture is intentionally data-driven: niches, questions, portfolio sections, project templates, and generation rules are stored as data so new career niches can be added without rewriting the application.

## Planned user roles

- Student
- Recruiter
- College
- Admin

## Development

This repository is being built from scratch as the PortfolioAI MVP.
